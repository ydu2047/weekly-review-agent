# Cursor Weekly Review Skill

A Cursor AI agent system for people who feel busy and productive every day but can't tell where their energy and attention actually go — and can't detect what's being neglected or whether consistent patterns exist across their life.

This is not a productivity tracker. It's a **life-coach agent** that reads your raw daily notes and surfaces behavioral patterns, emotional undercurrents, and blind spots you didn't notice yourself.

---

## Tool Compatibility

| Tool | How it works |
|---|---|
| **Cursor** | `.cursor/rules/` and `.cursor/skills/` load automatically — no setup needed |
| **Claude Code** | `CLAUDE.md` is read as project-level instructions; skill installable via `npx skills add https://github.com/ydu2047/weekly-review-agent --skill personal-weekly-review` |

Each tool reads only its own files and ignores the other's — they coexist cleanly.

---

## What It Does

You keep a running log of your week in `weekly_agenda.md`. When you ask the agent to run a review, it reads your notes, synthesises them through a coaching lens, and produces a narrative reflection — not a summary of tasks, but an observation of *you*: where your energy went, what you kept avoiding, what pattern is quietly forming across weeks.

Over months, the system builds a cross-week memory (`pattern_memory.md`) so each review is informed by everything before it. Quarterly reviews zoom out further to describe the shape of an entire season.

---

## Architecture

```
weekly_agenda.md          ← your raw activity log (append-only, never edited by agent)
      ↓
weekly_review_YYYY-Www.md ← narrative review, one file per week
      ↓
quarterly_review_YYYY-Qn.md ← seasonal reflection, reads weekly reviews only
      ↓
quarterly_pulse_log.md    ← one-line emotional fingerprint per quarter (permanent record)
```

`pattern_memory.md` is read **before** and updated **after** every weekly review, giving the agent continuity across weeks without re-reading all past files.

## Weekly Review Format

Each review contains five sections:

1. **The Week's Pulse** — the underlying vibe of the week in 2–4 sentences. No task recaps.
2. **Energy & Attention** — 1–2 flow moments and 1–2 friction points, synthesised (max 5 sentences).
3. **Notable Patterns** — 2–3 recurring observations across the week.
4. **The Unspoken Pattern** — one behavior the author likely hasn't noticed about themselves.
5. **The Coach's Question** — one open-ended question to carry into the next week.

Language auto-detects from your input: English notes → English review, Chinese notes → Chinese review.

## Getting Started

### 1. Set up your weekly log

Open `weekly_agenda.md` and start appending your weeks using this header:

```
## Weekly Agenda | YYYY-WXX | Mon DD – Sun DD
```

Write freely under each header — tasks completed, things that happened, how you felt, what you did or didn't do. The more honest and specific, the better the review.

### 2. Run a weekly review

Open a Cursor agent session in this project and say:

> "Run the review" or "Summarize the week"

The agent will read your latest week, generate `weekly_review_YYYY-Www.md`, and update `pattern_memory.md`.

### 3. Run a quarterly review

After 13 weeks, say:

> "Run the quarterly review" or "Generate the Q1 review"

The agent reads all weekly reviews from that quarter and generates `quarterly_review_YYYY-Qn.md`, then appends a one-line pulse to `quarterly_pulse_log.md`.

## Design Principles

**Append-only source data** — `weekly_agenda.md` is never modified. All synthesis happens in separate output files, so your raw record is always intact.

**No re-reading everything** — `pattern_memory.md` is a compact rolling summary (~60 lines max) that gives the agent multi-week memory without loading your entire history into context.

**Layered architecture** — each layer only reads the layer directly below it. The quarterly agent never touches `weekly_agenda.md`. This keeps each layer independent and fast.

**Language-aware** — reviews match the language of your input. Switch between languages freely across weeks.

---

## Tips

- Write notes during the week, not all at once on Sunday — the texture of daily observations produces better reviews than a retroactive summary.
- Don't clean up or filter your notes before running a review. Avoidances and incomplete items are signal, not noise.
- The Coach's Question at the end of each review is worth sitting with before the next one.
